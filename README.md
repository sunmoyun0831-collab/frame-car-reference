# FRAME 汽车设计参考助手

非官方 Chrome 扩展：浏览汽车之家时整理设计参考图——车型联想、图库多选、按车型和专题自动归档。

Unofficial Chrome extension for organizing car design references while browsing autohome.com.cn.

> **非官方声明**：本项目是个人开发的辅助工具，与汽车之家（autohome.com.cn）没有任何关联，也未获得其认可或授权。

## 功能

- **可调玻璃浮窗**：在汽车之家页面上显示一个可拖动、可缩放的浮窗，深色／浅色主题、磨砂强度、主题色均可调整。
- **车型实时联想**：输入时实时联想车型，点击直达该车型图库。
- **最近浏览与收藏**：自动记录看过的车型，常用车型可以收藏。
- **图库多选**：在图库页面勾选多张照片（每次最多 80 张），一次保存。
- **智能归档**：按「车型」和自建的「参考集」（如灯、轮毂、扶手）分文件夹保存，文件按 `车型_编号_分类_来源` 自动命名。
- **只保存原图**：仅使用页面明确提供的大图地址，不放大缩略图、不去水印、不绕过登录或安全验证。

## 安装

目前没有上架 Chrome 应用商店，需要手动加载：

1. 到本仓库的 [Releases](https://github.com/sunmoyun0831-collab/frame-car-reference/releases/latest) 页面，下载最新的 `FRAME-x.x.x.zip`。
2. 解压 zip，会得到一个 `FRAME-x.x.x` 文件夹。**打开它**，里面才是真正的扩展文件夹 `FRAME`（全大写）。
3. 先把 `FRAME` 文件夹放到一个固定位置，以后不要移动或删除它，否则扩展会失效。
4. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角的「开发者模式」。
5. 把 `FRAME` 文件夹**直接拖进**这个扩展管理页面，即可完成安装。
6. 打开或刷新汽车之家页面，即可看到 FRAME 浮窗。

> 注意：要拖的是里层的 `FRAME` 文件夹，不是外层的 `FRAME-x.x.x`。拖错一层会提示找不到 manifest 文件。

需要 Chrome 111 或更高版本，支持 Windows 和 macOS 桌面版。

更详细的操作说明见 [使用说明.md](./使用说明.md)。

## 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 在本机保存设置、收藏、最近浏览和下载记录 |
| `downloads` | 把照片保存到 Chrome 默认下载目录下的 `FRAME` 文件夹 |
| `*.autohome.com.cn`、`*.autoimg.cn` | 在汽车之家页面显示浮窗、读取车型联想和图片地址 |

本扩展不收集任何数据，也不向汽车之家以外的服务器发送数据。
